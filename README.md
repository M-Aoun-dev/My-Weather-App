# Weather App (React)

This is a simple and responsive Weather App built using React.  
It fetches real-time weather data from the Open-Meteo API and displays key information like temperature, wind speed, and weather conditions.

---

## Features

- Search weather by city name
- Displays current temperature
- Shows wind speed
- Dynamic weather icons based on conditions
- Error handling for invalid cities
- Clean UI with centered card layout

---

## Weather Logic

The app uses Open-Meteo weather codes and groups them into:

- Clear (Clear / Mainly Clear)
- Cloudy (Partly Cloudy / Overcast / Fog)
- Rain (Drizzle / Rain / Rain Showers)
- Thunderstorm (shown with default)
